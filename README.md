# VIZE ODEV
PROGRAMLAMAYA GİRİŞ VİZE ÖDEVİ

Bir Varmış Bir Yokmuş
Programlamaya Giriş dersi vize projesi. Bu web sitesi 10 masalın kısa özetini bir araya getirir. Ziyaretçiler masal kitaplığını gezebilir, masalları başlıklarına göre arayabilir ve seçtikleri masalın özetini okuyabilir.
Nasıl çalıştırılır?
Bir_Varmis_Bir_Yokmus_Internetsiz.html dosyasını indirip çift tıklayarak tarayıcıda aç. Masal kitaplığına geç, arama kutusuna bir masal adı yaz veya bir karttaki Özeti Oku düğmesine bas.

HTML, CSS, JavaScript ve kapak görseli aynı dosyada yer alır. Siteyi açmak için kurulum veya internet bağlantısı gerekmez.
Özellikler
- 10 masaldan oluşan kitaplık ve ayrı özet ekranı
- Yazdıkça sonuçları güncelleyen, Türkçe karakterlere uyumlu başlık araması
- Bilgisayar ve telefon ekranlarına uyum sağlayan kart düzeni
- Ana sayfa, kitaplık ve özet ekranları arasında gezinme
Kullanılan teknolojiler
Sayfanın yapısı HTML ile, görünümü içsel CSS ile hazırlandı. Masal kartları, arama ve ekran geçişleri içsel JavaScript ile çalışır.

Kapak görseli ChatGPT ile üretildi. Kod yazarken takıldığım bölümlerde ChatGPT’den destek aldım.
